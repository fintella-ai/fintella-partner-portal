# Competitive Intelligence Report — 2026-08-19

> **Baseline**: Prior scan [2026-05-06](./2026-05-06.md) — this report covers the **3-month delta** since that scan. Read the May 6 report for full competitor profiles; this document focuses on what's changed and new entrants not previously tracked.

---

## Summary

The IEEPA tariff refund market has matured significantly since the May 6 scan. **~60% of the $166B pool ($86B+) has been disbursed** by CBP as of August 4, 2026 — Phase 1 entries from April 20 have largely cleared, and **CAPE Phase 2 (unliquidated entries from protests and AD/CVD) went live June 29**. The window is tightening: the 80-day CAPE submission deadline clock that Fintella has been surfacing is now the most urgent UX differentiator in the space. Five significant new entrants were identified this scan: **Zollback** ($4.5M funded, AI drawback SMB play), **TariffCenter.ai** (subscription model, $19/mo), **Tarifflo** (managed AI + broker service), **1st Capital Financial** (claim financing/purchase), and **ES-003.com** (CAPE CSV export with traffic-light entry grading). No competitor has added TMS embedding, multi-client dashboards, or commission/referral tracking since the last scan. **Fintella's structural advantages remain intact.**

## Changes Detected in Core Tracked Competitors

### 1. Allied CHB — https://www.alliedchb.com/refunds
**Status: Active | No material changes since May 6**

- Core feature remains: CBP 7501 PDF drag-and-drop, no signup, licensed broker follow-through.
- Parses all IEEPA duty types (China/HK, reciprocal, tiered, country-specific); detailed per-entry breakdown.
- Data processing confirmed secure; no server storage.
- CAPE CSV generation: still not self-serve — routes to broker-managed filing.
- **Positioning unchanged**: "We handle it for you." Broker lead-gen funnel.
- No new features confirmed in this scan.

### 2. Flexport — https://tariffs.flexport.com/refunds
**Status: Active | Positioning sharpened post-CAPE Phase 2**

- AI Auditor is now the primary marketed feature — audits past customs entries for errors, files corrections, and pipelines into CAPE submission.
- Bulk entry report upload still uses Flexport's proprietary format (not ES-003 native).
- Post-Phase 2, Flexport is explicitly managing CAPE submissions for customers — full managed service.
- Blog content updated: "CBP Launches CAPE for IEEPA Tariff Refunds" (April 2026) and "Supreme Court IEEPA Ruling: Next Steps" educational content published.
- Requires Flexport account for the full automation pipeline.
- **Positioning update**: "Audit your customs broker" remains — now coupled with "we automate CAPE filing for you." More aggressive with broker displacement narrative.

### 3. UNIS / UNISCO — https://www.unisco.com/ieepa-refund-calculator
**Status: Active | Distribution expansion continues**

- ES-003 CSV/TXT upload, client-side processing, no signup — unchanged.
- Classification still covers IEEPA (9903.01/02), Section 301 (9903.88), Section 232, Section 122.
- ITEM Marketplace distribution channel (marketplace.item.com) confirmed active.
- No CAPE CSV export detected — still routes to UNISCO brokerage team.
- 180-day protest deadline tracking remains the headline UX feature.
- **No major feature additions confirmed this scan.**

### 4. The Trade Lab — https://thetradelab.ai/refund-calculator
**Status: Active | Broader AI platform positioning strengthening**

- Identifies Chapter 99 IEEPA codes, calculates refund per line.
- Platform now explicitly positions around AI-powered HTS classification and landed cost modeling as its broader offering; the refund calculator remains the free lead-generation entry point.
- Freemium model confirmed: free refund calculator, paid AI subscription for broader platform.
- **No CAPE CSV generation detected.**

### 5. TariffClaim.ai — https://tariffclaim.ai

**Status: Active | Content marketing expanded**

### 7. TADA — https://mytada.com
**Status: Active | Enterprise positioning unchanged**

- HTS Lookup + Tariff Estimator micro-apps active and updated for Section 122 surcharge (post-Feb 24, 2026).
- IEEPA recovery modeling updated post-SCOTUS ruling.
- Enterprise platform (AI Digital Twin, SKU-level modeling) unchanged.
- No CAPE/ES-003 filing tools.
- **Positioning unchanged**: complex enterprise supply chain intelligence, not a filing tool.

### 8. Wove — https://tariffs.wove.com/us/refunds
**Status: Active | ⚠️ API tier now publicly available**

- Free calculator (spreadsheet upload → PSC/Protest/CIT path breakdown) unchanged.
- **NEW**: Wove Tariff Calculator API publicly launched — brokers and developers can embed Wove's calculation engine into TMS/landed cost systems/quoting tools. Key API features:
  - Duty rate lookup by HS/HTS code (US, EU, Canada, Australia)
  - Stacked tariff calculation (Section 301 + 232 + IEEPA + Section 122 combined impact)
  - Historical rate lookup for any past date (critical for refund audit trails)
  - Classification traceable to specific tariff schedule, Federal Register notice, and effective date
- Featured in FreightWaves: "Wove speeds tariff change info for forwarders, TMS — and it's free."
- **⚠️ Threat assessment updated to HIGH**: API-for-TMS angle is a direct vector into Fintella's TMS embedding differentiation. No confirmed CargoWise/Magaya integration yet, but the capability exists.

### 8. SimplyDuty, Descartes CustomsInfo
**Status: Not direct IEEPA competitors — unchanged from May 6 assessment.**

## New Entrants (Since May 6, 2026)

### NE-A. Zollback — https://www.zollback.com
**Threat level: MEDIUM | Well-funded, SMB-focused, managed service**

- **Founded**: 2024, launched early 2026. $4.5M seed funded.
- **Founders**: Elena Zhao (Stanford PhD, ex-CBP) + Daniel Park (ex-Palantir, ex-Stripe).
- **Core offering**: AI-powered duty drawback + IEEPA refund platform for SMBs and mid-market importers.
  - Ingests trade docs in any format (PDF, spreadsheet, legacy exports) — no reformatting required.
  - Claims 15–20% more recovery vs. traditional drawback providers.
  - 10–15 working day turnaround vs. industry-standard 9–12 months.
- **Pricing**: Fully performance-based; percentage of recovered refund (rate decreases at volume). No upfront cost.
- **Traction**: $10M+ in tariff refunds processed; $1M ARR within first year.
- **IEEPA angle**: Treats IEEPA as a one-time opportunity distinct from the ongoing drawback program; positioned as best option for SMBs who can't navigate CBP bureaucracy.
- **No CAPE CSV generation, no TMS embedding, no multi-client dashboard** detected.
- **Positioning**: "You don't have to navigate this alone — we handle everything end-to-end."

### NE-B. TariffCenter.ai — https://tariffcenter.ai
**Threat level: LOW-MEDIUM | Only subscription-model entrant**

- **Model**: SaaS subscription, $19/month — the only paid subscription product in the tracked competitor set.
- **Features**:
  - AI HTS classification (photo upload or product description → instant classification with confidence scores).
  - Landed cost calculator across 29,794 product codes.
  - Policy tracker (SCOTUS rulings, executive orders, IEEPA challenges, Section 122 updates).
  - IEEPA Refund Status Tracker (monitors CBP CAPE updates).
  - HS Code Lookup to verify IEEPA applicability.
- **Blog content**: "How to File an IEEPA Tariff Refund via CAPE Portal (2026)" — step-by-step CAPE guide published.
- **Comparison page**: "TariffAI vs Enterprise Alternatives" at /compare — actively positioning against larger tools.
- **No CAPE CSV generation, no ES-003 upload, no broker dashboard** detected.
- **Positioning**: Trade compliance platform for repeat users who need ongoing tariff intelligence, not just a one-time refund estimate.

### NE-C. Tarifflo — https://www.tarifflo.com
**Threat level: MEDIUM | AI + licensed broker managed service**

- **Model**: Managed service — AI models + in-house licensed customs brokers. Performance-based pricing implied.
- **Features**:
  - Audits import entries for HTS misclassification (found 1-in-8 entries overpaid due to incorrect HTS codes).
  - Files Post Summary Corrections (PSC) on behalf of importers.
  - Coordinates IEEPA refund process end-to-end.
  - Pre-audit to validate claims before submission (reduces rejection risk).
- **Track record**: Audited 1M+ import entries; recovering "millions of dollars" in overpaid duties (per press release, June 2026).
- **No self-serve calculator, no broker dashboard, no TMS embed** detected.
- **Positioning**: "We audit and file — you just provide documents." AI-powered managed service competing with customs brokers.

### NE-D. 1st Capital Financial — https://1stcapitalfinancial.com/ieepa-tariff-refund/
**Threat level: LOW (different business model) | Unique financing angle**

- **Model**: Financial services — claim purchase and advance funding, NOT a filing tool.
- **Features**:
  - **IEEPA Tariff Advance**: Non-recourse purchase of up to 90% of claim value in 1–2 weeks.
  - **File and Fund Program™**: Full filing + funding bundle covering CAPE Phase 1, 2, and 3.
  - Trade advisory team oversees recovery without requiring broker change.
  - Success fee: 8–15% of recovery. Minimum claim for funding: $100K.
  - Free refund calculator at /calculator.
- **Track record**: $10B+ in financing and refunds recovered across 90,000+ businesses (historic, not IEEPA-specific).
- **Positioning**: "Get cash now — don't wait 60–90 days for CBP to process your refund." Complements rather than competes with filing tools; more analogous to TariffClaim.ai's investor angle.

### NE-E. ES-003.com — https://es-003.com
**Threat level: MEDIUM-HIGH | CAPE CSV export with traffic-light grading**

- **Tool**: Standalone ACE ES-003 upload calculator with CAPE Declaration CSV export.
- **Features**:
  - Upload ES-003 report → entries graded **Green** (refund-eligible, CAPE-ready), **Yellow** (borderline/uncertain), **Red** (not eligible).
  - **Green entries exported as CAPE Declaration CSV** — direct CAPE submission path.
  - Interest calculation using §1505 accrual from payment date.
  - Country-of-origin filtering for refund estimate.
  - Deadline tracking per entry.
- **Data handling**: Local browser processing confirmed (no server upload).
- **Connection to UNIS**: URL pattern and feature overlap with UNISCO strongly suggest this is either a white-label of the UNIS tool or a related UNIS project spun out as a standalone domain.
- **⚠️ Threat note**: The Green/Yellow/Red grading + one-click CAPE CSV export is cleaner UX than what's been observed elsewhere. If this is independent of UNIS, it's a new CAPE CSV competitor alongside CustomsGenius (flagged in May 6 report).

## Recommended Actions

### 1. Add Phase 2 urgency to all deadline messaging
Phase 1's 80-day CAPE window (from April 20) has now passed its first threshold. **Shift urgency language to CAPE Phase 2** (open since June 29) and the 180-day protest window for liquidated entries. Competitors with no deadline tracking are silent on this — Fintella should be the loudest voice on "Phase 2 is live, you may still have time." Update the TIE landing page countdown to reference Phase 2 eligibility.

### 2. Add traffic-light entry grading to ES-003 output
ES-003.com (likely a UNIS spin-off) has shipped a clean Green/Yellow/Red grading UX alongside CAPE CSV export. This is better than a raw table for brokers presenting results to importer clients. **Recommended**: Add color-coded eligibility status (Green = CAPE-ready, Yellow = needs review, Red = ineligible) to the per-entry analysis view. This is a UX improvement over the current table and closes the gap with ES-003.com.

### 3. Counter Wove's API tier with a named TMS embed story
Wove now has a public tariff calculator API getting FreightWaves coverage and positioned for TMS embedding. While no confirmed CargoWise/Magaya integration has appeared, it's a matter of time. **Recommended**: Publish a dedicated page at fintella.partners/for-tms-users (or equivalent) explicitly naming the CargoWise and Magaya integrations. A named case study or demo video of the TMS widget in action would be the strongest defense — Wove has an API, Fintella has a live integration. That's a meaningful distinction that should be visible and searchable.
