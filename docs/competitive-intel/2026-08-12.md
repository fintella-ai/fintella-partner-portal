### 2. 🟡 PRIORITY — Manual check of CustomsGenius within 7 days
CustomsGenius was the only competitor with confirmed CAPE CSV generation and AI-powered analysis (as of May 2026). At $0.25/line, a mid-sized broker processing 5,000 entries/quarter pays $1,250 — not trivial. If they have lowered pricing, added bulk/subscription tiers, or gained major broker clients in the last 97 days, that directly affects Fintella's differentiation story. **Recommended**: Manual browser check of customsgenius.com for pricing page, case studies, or broker partner announcements.

### 3. 🟡 PRIORITY — Check Wove for TMS partnership announcements
Wove's API-for-brokers was identified as the only plausible attack vector on Fintella's TMS embedding advantage. A CargoWise or Magaya integration announcement from Wove would significantly narrow Fintella's moat. **Recommended**: Check tariffs.wove.com for API documentation updates and LinkedIn/press for partnership news.

### 4. 🟢 ONGOING — Advance Section 301/232/122 classification feature
UNIS, ITEM Marketplace, and The Trade Lab all classify entries beyond IEEPA. Brokers consistently need the full picture. This remains an open gap vs. UNIS's most visible differentiator. If CAPE Phase 2 (liquidated entries) has been announced since May, this becomes even more urgent — protest filings overlap heavily with Section 301 compliance.

### 5. 🟢 ONGOING — Surface CAPE CSV pre-validation as primary differentiator
CustomsGenius has CAPE CSV; Fintella has CAPE CSV + pre-validation (entry number CBP mod-10, batch size limits, liquidation status flags). This is Fintella's actual edge. The marketing page should name the validation rules explicitly — "we catch errors before CBP rejects your CAPE submission" is a concrete promise no competitor can match without building what Fintella already has.
