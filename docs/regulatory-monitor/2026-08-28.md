### 2. ✅ INFORMATIONAL — Section 122 CIT Ruling Stayed Pending Appeal

**Status**: No code change needed; notes added to seed file

On **May 7, 2026**, the U.S. Court of International Trade (CIT) held that Section 122 tariffs were unlawful (balance-of-payments deficit condition not satisfied). However:
- The Federal Circuit **stayed the injunction** pending the government's appeal
- Collection of Section 122 duties continued through the tariff's July 24, 2026 statutory expiration
- **No CAPE refund mechanism exists** for Section 122 entries (Feb 24 – Jul 23, 2026)
- Relief is currently limited to the named plaintiffs: Burlap & Barrel, Basic Fun!, and the State of Washington

**Impact on calculator**: No change. `checkEligibility()` correctly treats Section 122 period entries as outside IEEPA scope (`IEEPA_END_DATE = 2026-02-23`). If the Federal Circuit or Supreme Court eventually extends refund relief to all importers for Section 122, a new CAPE mechanism or litigation path would need to be added at that time.

### 3. ✅ CONFIRMED — CAPE Phase 2 Live Since June 29, 2026 (No New August Updates)

**Status**: No code change needed

CAPE Phase 2 launched June 29, 2026 per CSMS #69066837. Phase 2 allows entry types 01, 02, and 06 that are **flagged for reconciliation** (but where the Type 09 reconciliation entry has NOT yet been filed) to use the CAPE automated refund path.

**Critical caveat (no code change needed but worth noting)**: If the importer files the Type 09 reconciliation entry BEFORE requesting CAPE, those underlying entries are permanently locked out of CAPE. The `EXCLUDED_ENTRY_TYPES` set in `tariff-calculator.ts` correctly keeps Type 09 excluded (you can't CAPE a reconciliation entry itself). Types 01/02/06 were already eligible in the code.

No new CAPE announcements were found for August 2026.
