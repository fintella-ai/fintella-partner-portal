## 1. CAPE Phase 2 — Reconciliation-Flagged Entries (ACTIONABLE — CODE UPDATED)

**Source**: CSMS #69035485  
**Effective**: June 29, 2026

CBP expanded CAPE to accept entries of types 01, 02, and 06 that are "flagged for reconciliation" in ACE — *provided* the Type 09 reconciliation entry has not yet been filed. Key points:

- **Window**: Same as Phase 1 — unliquidated entries or entries liquidated within 80 days.
- **Excluded**: Entries where the Type 09 reconciliation entry is already on file. These are not in the June 29 deployment; CBP will address them in a future CAPE phase.
- **Process**: CAPE removes the IEEPA duties from the flagged entry before the reconciliation entry is filed, separating the IEEPA refund from the reconciliation calculations.
- **Deadline warning**: If the reconciliation filing deadline is within 30 days, the trade should prioritize filing the reconciliation entry first.

**Code change made** (`src/lib/tariff-calculator.ts`):
- Added `isFlaggedForReconciliation?: boolean` and `hasFiledReconciliationEntry?: boolean` fields to `EntryForEligibility`.
- Added exclusion check (step 4a in `checkEligibility()`): if both flags are true, returns `status: "excluded_recon_filed"` with `filingMethod: "none"` and note pointing to future CAPE phase.
- Updated `getRoutingBucket()` comment to include `excluded_recon_filed` in the `legal_required` bucket.
- Source: https://content.govdelivery.com/accounts/USDHSCBP/bulletins/41d65dd

**No code change needed today.** If Phase 3 launches, consider adding `"cape_phase3"` as a `FilingMethod` value.
