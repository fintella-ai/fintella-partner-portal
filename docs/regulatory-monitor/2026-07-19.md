## ACTIONABLE — Code changes in this PR

### 1. CAPE Phase 2 — Launched June 29, 2026

**Source:** CBP CSMS #68340863; CBP.gov/trade/programs-administration/trade-remedies/ieepa-duty-refunds; Thompson Hine SmarTrade (https://www.thompsonhinesmartrade.com/2026/06/cbp-confirms-june-29-2026-ieepa-tariff-refund-process-phase-2-launch/)

**What changed:** CAPE Phase 2 went live June 29, 2026, expanding CAPE eligibility to entry types 01, 02, and 06 that are **flagged for reconciliation**, provided the corresponding Type 09 reconciliation entry has **not yet been filed**.

Key Phase 2 rules:
- File the CAPE declaration **before** filing the Type 09 reconciliation entry — once Type 09 is filed, the underlying entries become ineligible for CAPE
- Exception: if the Type 09 deadline is within 30 days, prioritize the reconciliation entry
- CAPE removes IEEPA duties from the flagged entries prior to the reconciliation filing

**What did NOT change:**
- Type 09 (the reconciliation entry itself) remains excluded from CAPE
- Type 47 (drawback) remains excluded from all CAPE phases
- Types 08 and 23 remain excluded
- The 80-day liquidation window for automated processing is unchanged

**Code updated:** `src/lib/tariff-calculator.ts`
- `EXCLUDED_ENTRY_TYPES` comment updated from "Phase 1" to "all phases"
- `CAPE_PHASE1_LIQUIDATION_WINDOW_DAYS` JSDoc updated to reference Phase 1/2
- `FilingMethod` `cape_phase1` description updated to note Phase 2 coverage
- Error/reason strings updated throughout `checkEligibility()`
- `EXCLUDED_ENTRY_TYPES` set values **unchanged** (08, 09, 23, 47 still excluded)

**TODO (not in this PR):** Add `isFlaggedForReconciliation?: boolean` to `EntryForEligibility` interface and a `"cape_phase2"` `FilingMethod` variant so the UI can display distinct Phase 2 messaging for reconciliation-flagged entries.

### 4. CIT / Federal Circuit — Government appeals universal refund order

**Source:** Holland & Knight (https://www.hklaw.com/en/insights/publications/2026/06/ieepa-tariff-refund-update-government-appeals); Foley & Lardner (https://www.foley.com/insights/publications/2026/06/what-every-multinational-should-know-about-the-governments-appeal-of-judge-eatons-universal-ieepa-tariff-refunds-order-and-why-it-is-claiming-it-can-keep-billions-of-dolla/)

**What happened:** On May 29, 2026 DOJ filed a notice of intent to appeal the CIT's universal injunction in **Euro-Notions Florida v. United States** (the current lead IEEPA refund case after Atmus Filtration was dismissed). DOJ argues the CIT exceeded its authority by ordering CBP to reliquidate entries of importers who never filed at the court.

- If the Federal Circuit stays the injunction, importers who haven't filed at the CIT may lose access to CAPE Phase 3 (finally-liquidated entries)
- CAPE Phase 3 (for finally-liquidated entries, available only to CIT filers) is on track for "late July 2026"

**Code impact:** No code change needed now. The existing `filingMethod: "litigation"` path for entries past the 180-day protest window correctly reflects that finally-liquidated refunds require a CIT filing. CAPE Phase 3 then processes those refunds on the backend.

**Monitor:** Watch for Federal Circuit stay ruling and CAPE Phase 3 launch announcement.
