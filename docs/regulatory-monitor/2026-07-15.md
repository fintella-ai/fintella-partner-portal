## 3. CAPE Phase Status

### Phase 1 (live April 20, 2026)
Covers unliquidated entries and entries liquidated within 80 days. Entry types 01, 02, 06.  
**Source:** CBP CSMS #68340863 — https://content.govdelivery.com/accounts/USDHSCBP/bulletins/412cc7f

### Phase 2 (live June 29, 2026)
Covers entries of types 01/02/06 that are flagged for reconciliation but where the corresponding type-09 reconciliation entry has not yet been filed. Same 80-day liquidation window as Phase 1.

**Key stat:** ~4.36 million entries **failed** Phase 2 processing as of July 3, 2026. Importers with failed entries are in a holding pattern pending CBP remediation.

**Calculator impact:** Type-09 reconciliation entries themselves remain excluded from CAPE (they are the *child* reconciliation entries, not the parent entries Phase 2 opened). `EXCLUDED_ENTRY_TYPES` unchanged. Comment block in `tariff-calculator.ts` updated to document Phase 2 and its scope.

**Sources:**
- Thompson Hine (Phase 2 launch): https://www.thompsonhinesmartrade.com/2026/06/cbp-confirms-june-29-2026-ieepa-tariff-refund-process-phase-2-launch/
- Phase 2 failures: https://customsandinternationaltradelaw.com/2026/07/03/cape-phase-two-refund-failures/
- CBP IEEPA refund page: https://www.cbp.gov/trade/programs-administration/trade-remedies/ieepa-duty-refunds

### Phase 3 (targeted end of July 2026)
Will cover finally-liquidated entries where the 90-day CBP reliquidation window has already closed. **Legal dispute:** Government argues (Federal Circuit appeal No. 26-1898, filed June 2, 2026) that Phase 3 refunds are available only to importers who have filed suit at the CIT. If the government prevails, non-litigant importers with finally-liquidated entries cannot access Phase 3 via CAPE — their only path is filing new CIT litigation.

**Calculator impact (pending Phase 3 launch):** Once Phase 3 launches, finally-liquidated entries in the 80–180 day post-liquidation window may become eligible via CAPE rather than requiring a formal protest — but only if the Federal Circuit resolves the non-litigant eligibility question favorably. No code change yet.

**Source:** https://www.greenworldwide.com/cape-phase-3-for-ieepa-tariff-refunds-on-track-for-end-of-july-as-federal-circuit-appeal-continues/

### CAPE Statistics (CBP declaration, Euro-Notions, July 1, 2026)
- 18.1 million entries cleared file validation
- 15.92 million entries liquidated/reliquidated without IEEPA duties
- ~$71.06 billion in refunds certified and sent to Treasury
