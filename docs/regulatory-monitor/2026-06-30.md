## 1. CAPE Phase 2 — ACTIONABLE (code updated)

**Source**: CBP CSMS #69035485 (published June 23, 2026, effective June 29, 2026)  
**Reference**: https://content.govdelivery.com/bulletins/gd/USDHSCBP-41d65dd  
**Law firm summaries**: https://www.thompsonhinesmartrade.com/2026/06/cbp-confirms-june-29-2026-ieepa-tariff-refund-process-phase-2-launch/

### What changed

CBP deployed CAPE Phase 2 on June 29, 2026, expanding automated IEEPA refund processing to reconciliation-flagged entry types.

**Phase 2 scope**:
- Accepts entry types **01, 02, and 06** that are **flagged for reconciliation** in ACE
- Only where a Type 09 reconciliation entry has **not yet been filed**
- Same liquidation window as Phase 1: unliquidated entries OR entries liquidated within 80 days
- Once a CAPE Phase 2 declaration is accepted, CBP removes the IEEPA duties from the flagged entries, then the importer may file the Type 09 reconciliation entry separately

**Still excluded from Phase 2**:
- Entries where a Type 09 reconciliation entry is already on file (pending a future CAPE phase)
- Entry type 08 (informal), 09 (reconciliation entry itself), 23 (temporary importation), 47 (drawback)
- Entries liquidated more than 80 days ago (still require formal protest)

### Code changes made

**`src/lib/tariff-calculator.ts`**:
- Added `"cape_phase2"` to `FilingMethod` type
- Added `isFlaggedForReconciliation?: boolean` and `hasExistingType09?: boolean` to `EntryForEligibility`
- Added step 3b in `checkEligibility()`: reconciliation-flagged entries with an existing Type 09 return `excluded_type` with reason pointing to future CAPE phase
- Updated step 6 (liquidated) and step 7 (unliquidated) to return `filingMethod: "cape_phase2"` for reconciliation-flagged entries without a Type 09

**`src/lib/tariff-risk-score.ts`**:
- Added `cape_phase2: 0` to `FILING_RISK` record (same risk level as Phase 1 — automated CBP process)

## 2. Section 122 Tariff Expiration — MONITORING (notes updated)

**Source**: Proclamation 11012 (Feb 23, 2026); 19 U.S.C. § 2132  
**Reference**: https://www.bhfs.com/insight/trump-tariffs-upcoming-deadlines/  
**Section 122 guide**: https://www.peacocktariffconsulting.com/section-122-tariff-guide/

### Status as of June 30, 2026

The Section 122 10% global import surcharge (HTS 9903.03.01) **expires July 24, 2026 — 24 days from now**.

Key facts:
- **Rate**: Still 10% (no formal proclamation to raise to 15% has been issued)
- **Extension**: The president **cannot** extend Section 122 unilaterally past 150 days; only Congress can
- **Legal challenge**: CIT invalidated Section 122 in *Oregon v. United States / Burlap and Barrel, Inc. v. United States* (Slip Op. 26-47, May 7, 2026)
- **Stay**: Federal Circuit granted stay June 11, 2026 (Nos. 2026-1804/1805) — tariffs remain collectible from virtually all importers while the government's appeal proceeds
- **What comes next**: USTR commenced two Section 301 investigations (forced labor / excess industrial capacity) whose hearings track the July 24 expiration date; Section 301 tariffs are the most likely replacement authority

### Code changes made

- Updated `S122-01` notes in `prisma/seed-data/ieepa-tariff-rates.json` to reflect CIT ruling, Federal Circuit stay, approaching expiration, and Section 301 successor trajectory
- Updated `_metadata` with version 1.1.0, today's date, and new source citations

## 3. Euro-Notions IEEPA Universal Refund Appeal — MONITORING (no code change)

**Source**: Federal Circuit Case No. 26-1898 (filed June 2, 2026)  
**Reference**: https://www.foley.com/insights/publications/2026/06/what-every-multinational-should-know-about-the-governments-appeal-of-judge-eatons-universal-ieepa-tariff-refunds-order-and-why-it-is-claiming-it-can-keep-billions-of-dolla/  
**CBP position**: https://www.sheppard.com/insights/blogs/from-cape-to-cope-cbp-reverses-position-on-universal-ieepa-duty-refunds

### Status

The government appealed the CIT's order (April 7, 2026) requiring CBP to refund IEEPA duties on **finally liquidated entries** (liquidated >90 days ago). CBP additionally filed a motion on May 29, 2026 asserting it lacks authority to issue refunds on finally liquidated entries without an importer-specific court judgment.

Impact on the calculator:
- Entries with `filingMethod: "litigation"` (liquidated >180 days ago, protest window expired) — no change; the calculator correctly routes these to litigation already
- If the Federal Circuit rules for the government, importers with finally-liquidated entries have NO administrative refund path and must file individual CIT actions — the calculator's `"litigation"` routing would remain accurate

**No code change required** — the current eligibility logic already correctly routes finally-liquidated entries to `"litigation"` status.
