- **10%** — 14 economies (lower tier)
- **12.5%** — 46 economies (default tier)
- **HTS codes:** 9903.05.20 through 9903.06.21 (65 country-level headings + exemption headings)

**Impact on TIE calculator:** None directly. These are new tariffs on *future* imports. They are **not refundable under CAPE** — CAPE covers only IEEPA-period duties (Feb 1, 2025 – Feb 23, 2026). The seed data metadata has been updated to note the Section 301 replacement regime.

**No new IEEPA activity.** The SCOTUS termination (Feb 20, 2026) stands. No new IEEPA executive orders were issued. The Section 301 tariffs are a distinct authority.

## 3. CAPE Phase 2 Live — June 29, 2026 ✅ Updated in tariff-calculator.ts

**Sources:**  
- [CBP IEEPA Duty Refunds page](https://www.cbp.gov/trade/programs-administration/trade-remedies/ieepa-duty-refunds)  
- [M.E. Dey & Co. — CAPE Phase 2 Is Live](https://www.medey.com/cape-phase-2-is-live-here-is-what-that-means-for-ieepa-refunds/)  
- [TariffsTool Guide — Phase 2 Launch](https://www.tariffstool.com/guides/cape-phase-2-launch-date-whats-coming-may-2026)

CBP deployed CAPE Phase 2 on **June 29, 2026**, expanding CAPE eligibility:

| Entry Status | Phase 1 (Apr 20) | Phase 2 (Jun 29) |
|---|---|---|
| Unliquidated, non-AD/CVD | Eligible | Eligible |
| Liquidated ≤ 80 days | Eligible | Eligible |
| Flagged for reconciliation, type 09 NOT filed | **Rejected** | **NOW ELIGIBLE** |
| Flagged for reconciliation, type 09 already filed | Rejected | Still rejected |
| Type 09 reconciliation entries | Excluded | Still excluded |
| Type 47 drawback entries | Excluded | Still excluded |

Phase 2 allows entries of types 01, 02, 06 that are "flagged for reconciliation" in ACE (meaning the importer indicated at entry they would file a reconciliation) to now be submitted via CAPE — provided the type 09 reconciliation entry has NOT yet been filed. Once accepted, the importer may then file the type 09 after CAPE removes the IEEPA duties.

**Changes made to `src/lib/tariff-calculator.ts`:**
- Added `FilingMethod` value `"cape_phase2"`
- Added `isReconciliationFlagged?: boolean` field to `EntryForEligibility`
- Added Phase 2 eligibility path in `checkEligibility()` (step 4b)
- Updated `EXCLUDED_ENTRY_TYPES` comment to clarify Phase 2 scope
- Updated `FilingMethod` docstring

**Changes made to `src/lib/tariff-risk-score.ts`:**

## 4. CIT July 2026 Ruling — Refunds to Litigants on Finally Liquidated Entries (Informational)

**Source:** [Davis Wright Tremaine — IEEPA Duty Update: Trade Court Orders Refunds to Litigants on Finally Liquidated Entries](https://www.dwt.com/insights/2026/07/ieepa-duty-refunds-cit-orders)

The Court of International Trade issued an order in July 2026 directing CBP to refund IEEPA duties on finally liquidated entries for importers who have active CIT litigation (related to Euro-Notions Florida, Inc. v. United States, No. 25-00595). This is a narrow ruling applicable only to litigants.

**Impact on TIE calculator:** None. The calculator's protest deadline logic (180-day window under 19 U.S.C. §1514) is correct for non-litigants. Entries liquidated >180 days ago already route to `filingMethod: "litigation"`. The CIT ruling confirms that path leads to potential recovery for active plaintiffs. No code change warranted — this is an affirmation, not a rule change.

**Monitoring note:** The broader question of whether non-litigant importers with finally liquidated entries can recover (without suing) remains unresolved in Euro-Notions / V.O.S. Selections. Watch for further CIT rulings.
