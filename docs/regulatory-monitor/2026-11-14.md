### 3. CAPE Phase 3 — Status
**Result: Launched October 6, 2026. No November changes found. No code update needed.**

CAPE Phase 3 launched October 6, 2026 for a narrow set of importers:
- Eligibility: Companies that **filed CIT suit**, obtained a court order directing reliquidation, and submitted a valid IOR number by July 30, 2026.
- Scope: Finally liquidated entries (~$11.4B, ~6.9% of IEEPA duties per CBP estimate).
- Non-litigating importers with finally liquidated entries still have no confirmed CAPE path.

**Calculator impact:** None. The existing `"litigation"` `FilingMethod` for entries where the protest window has expired is the correct advice. Importers using CAPE Phase 3 already have court orders, which the litigation path routes toward. The `EXCLUDED_ENTRY_TYPES` set (`"08"`, `"09"`, `"23"`, `"47"`) correctly matches CBP's confirmed Phase 1/2/3 exclusions (Type 09 reconciliation and Type 47 drawback remain excluded from all CAPE phases).

### 4. CAPE Phase 2 — Reconciliation-Flagged Entries
**Result: Launched June 29, 2026. No November changes.**

CAPE Phase 2 accepts entries flagged for reconciliation where the Type 09 reconciliation entry has NOT yet been filed. The key rule: the CAPE declaration must be filed BEFORE the Type 09 reconciliation entry. After the Type 09 is filed, the underlying entries are locked out of CAPE.

**Calculator impact:** None — the existing `"09"` exclusion in `EXCLUDED_ENTRY_TYPES` correctly reflects this. The UI should be advising users to file CAPE before Type 09.

### 5. CIT Docket — Slip Op. 26-123 (Freestyle World Class Certification)
**Result: Procedural step only. No code/data change needed.**

The CIT certified a class on **October 8, 2026** in Freestyle World v. United States (No. 26-01088). The class covers importers who paid IEEPA duties but are NOT already in separate CIT litigation. The court's goal is a class-wide liquidation/reliquidation order covering all IEEPA entries.

Key implications:
- Class members must **wait for class-wide relief** — they are NOT currently eligible for CAPE Phase 3.
- Importers with separate CIT actions are excluded from the class and get individual relief.
- The government may appeal the certification order.

**Calculator impact:** None. The `"litigation"` path remains correct for finally-liquidated entries outside the protest window.
