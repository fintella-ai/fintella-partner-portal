## ⚠️ ACTIONABLE CHANGE — Code Updated

### Warehouse Entry Types 21 & 22 Excluded from CAPE (CSMS #69127837)

**Source:** [CSMS #69127837 – UPDATE: CAPE for IEEPA Refunds – Warehouse Entries](https://content.govdelivery.com/bulletins/gd/USDHSCBP-41ece9d)  
**Issued:** July 2, 2026 | **Effective:** July 7, 2026

CBP updated CAPE to reject warehouse entries (entry types 21 and 22). Any CAPE Declaration submitted on or after July 7 with a Type 21 or Type 22 entry receives an "ENTRY TYPE NOT ALLOWED" error. The rationale is that IEEPA duties were collected at the **withdrawal** stage (types 31, 32, 34, 38), not at the warehouse deposit stage, so refunds should be filed on the withdrawal entries.

**Impact on calculator:**
- `src/lib/tariff-calculator.ts` — `EXCLUDED_ENTRY_TYPES` updated: added `"21"` and `"22"`
- Reason message updated to explain the correct path (file on the corresponding withdrawal entry)

**Also noted:** Effective June 29, 2026, CAPE now accepts entries flagged for reconciliation (types 01, 02, 06) where the reconciliation entry (type 09) has not yet been filed (CSMS #69035485). This is an expansion, not a restriction — entries that were previously rejected due to an open reconciliation flag are now accepted. No code change needed; type 09 itself remains excluded.

### 2. Brazil 25% Section 301 Tariff — Effective July 22, 2026 (tomorrow)

**Source:** [USTR Notice of Action — Brazil (EY Tax News)](https://taxnews.ey.com/news/2026-1530-ustr-issues-notice-of-action-imposing-25-percent-section-301-tariffs-on-imports-from-brazil-effective-22-july-2026) | [KPMG](https://kpmg.com/us/en/taxnewsflash/news/2026/07/ustr-25-percent-tariffs-imports-brazil.html)

USTR finalized a 25% Section 301 tariff on all Brazilian goods (investigation: digital trade, IPR, deforestation, ethanol market access), effective July 22, 2026. Excluded: Section 232 goods, civil aircraft/parts, pharmaceuticals, humanitarian donations, personal baggage.

**Impact on refund calculator:** None. This is a forward-looking duty on new imports. Historical IEEPA duties on Brazil-origin goods (Feb–Feb window) remain refundable via CAPE as before. No seed data update warranted — this is not an IEEPA rate.

**Watch:** If the calculator gains a "current rate" lookup feature, Brazil would need a Section 301 entry at 25% from July 22, 2026.

### 4. CAPE Phase 3 — Expected Late July 2026 (Finally Liquidated Entries)

**Source:** [CIT CAPE Phase 3 Order — customsandinternationaltradelaw.com](https://customsandinternationaltradelaw.com/2026/07/16/ieepa-cape-phase-three-refunds/) | [Green Worldwide Shipping](https://www.greenworldwide.com/cape-phase-3-for-ieepa-tariff-refunds-on-track-for-end-of-july-as-federal-circuit-appeal-continues/)

CIT issued an order on July 15, 2026 directing CBP to reliquidate certain finally liquidated entries ahead of CAPE Phase 3. CBP confirmed Phase 3 programming will be ready in late July 2026. Key constraint: Phase 3 refunds process **only for importers who have filed CIT lawsuits** (~3,700 cases).

**Impact on eligibility logic:** None immediately. The current `checkEligibility()` already correctly routes finally liquidated entries (liquidated >180 days ago) to `filingMethod: "litigation"` and entries 80–180 days post-liquidation to `filingMethod: "protest"`. Phase 3 doesn't create a new automated path for entries outside the protest window.

**Watch:** If CBP announces a Phase 3 CSMS that opens a new CAPE path for *all* finally liquidated entries (not just CIT litigants), `EXCLUDED_ENTRY_TYPES` and the `excluded_expired` status logic may need updating. No action yet.
