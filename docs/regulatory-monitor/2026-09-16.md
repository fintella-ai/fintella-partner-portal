## 3. Section 301 Forced-Labor Tariffs — Effective July 24, 2026 (DOCUMENTED — NOT AFFECTING CALCULATOR)

**Finding:** New Section 301 tariffs took effect July 24, 2026, replacing Section 122. These target 60 economies for failure to prohibit forced-labor imports. ## 4. CAPE Phase 2 — Launched June 29, 2026 (DOCUMENTED — NO CODE CHANGE NEEDED)

**Finding:** CBP deployed CAPE Phase 2 on June 29, 2026 (CSMS #69035485). Phase 2 expands eligible entries to include types 01, 02, 06 that are **flagged for reconciliation** but where the Type 09 reconciliation entry has NOT yet been filed. CBP estimates $28.7 billion in additional refunds across ~2.8 million entries.

**Critical nuance:** Type 09 reconciliation entries themselves remain excluded. Type 47 drawback remains excluded. The Phase 2 change only affects entries of types 01/02/06 that carry a reconciliation flag — these pass through Phase 2 as long as no Type 09 has been filed.

**Code impact:** `EXCLUDED_ENTRY_TYPES = new Set(["08", "09", "23", "47"])` in `src/lib/tariff-calculator.ts` remains **correct** and requires no changes. Entry types 01, 02, 06 (including those flagged for reconciliation) are already eligible in the calculator. The Phase 2 change does not alter which entry type codes are excluded.

**Sources:**

- https://diaztradelaw.com/cape-ieepa-duty-refunds/
- https://www.cbp.gov/sites/default/files/2026-07/26_0723_trade_information_notice_CAPE.pdf

**Change made:** Added `capePhase2` block to seed data documenting scope, eligibility, and calculator guidance. Updated Type 09 excluded-entry note in `capePhase1.eligibleEntryTypes.excluded`.
