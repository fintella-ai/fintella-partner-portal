## 1. Section 122 Expired; Section 301 (Forced Labor) Tariffs Now in Effect

**Status:** CONFIRMED — effective July 24, 2026  
**Impact:** Rate database update (seed data) — `supersededBy` on S122-01 updated; two new S301 entries added

### What happened

The Section 122 global 10% surcharge expired at 12:01 AM ET on July 24, 2026 — its 150-day statutory maximum. At the exact same moment, USTR's new Section 301 "forced labor" tariffs took effect under 19 U.S.C. §2411.

USTR announced the final action on July 23, 2026 (Federal Register Notice), following a June 2, 2026 findings report covering 60 economies' failure to ban imports produced with forced labor.

### New tariff rates

| Rate | Countries |
|------|-----------|
| **10%** | Argentina, Bangladesh, Cambodia, Canada, Ecuador, El Salvador, Guatemala, Honduras, India, Indonesia, Jordan, Malaysia, Mexico, Pakistan, Sri Lanka, Trinidad & Tobago, United Kingdom (18 economies) |
| **12.5%** | All other ~42 economies including China, Brazil, Vietnam, Russia, South Korea, Thailand, Japan, EU members |

**HTS codes:** 9903.05.20 – 9903.06.21 (Chapter 99 range)  
**CBP filing guidance:** CSMS #69326983  
**No statutory sunset** (Section 301 has no built-in expiration date)

### Key exemptions

- USMCA-compliant goods from Canada and Mexico: **exempt**
- CAFTA-DR textile/apparel (El Salvador, Guatemala, Honduras, and CAFTA-DR parties): **exempt**  
- In-transit goods loaded before July 24, 2026 and entered before July 28, 2026: **exempt**

### CAPE refund impact

**None** — Section 301 tariffs are NOT IEEPA tariffs and are not subject to CAPE refunds. The S301 entries in the rate database are for informational completeness only.

## 2. CAPE Phase 2 Launched — Reconciliation-Flagged Entries Now Eligible

**Status:** CONFIRMED — live June 29, 2026  
**Impact:** `checkEligibility()` updated — new `isFlaggedForReconciliation` / `hasReconciliationEntry` fields; `FilingMethod` gains `cape_phase2`; new `excluded_recon_filed` status

### What happened

On June 29, 2026, CBP expanded the CAPE process to include entries of types 01, 02, and 06 that are **flagged for reconciliation** but for which **no Type 09 reconciliation entry has yet been filed**. Prior to Phase 2, these entries were excluded from CAPE.

CBP estimates Phase 2 covers approximately **$28.7 billion in additional refunds** across ~2.8 million entries.

### Critical filing-sequence warning

> **Do NOT file the Type 09 reconciliation entry before submitting the CAPE declaration.** Once the Type 09 is filed, the underlying entries are locked out of CAPE Phase 2 — permanently for this phase. If your reconciliation filing deadline is within 30 days, CBP says to prioritize the reconciliation entry, but otherwise file the CAPE declaration first.

### Phase 2 scope

- ✅ Entry types 01, 02, 06 flagged for reconciliation **without** a Type 09 on file → now eligible
- ❌ Entries flagged for reconciliation **with** a Type 09 already filed → excluded from Phase 2 (future CAPE phase, not yet announced)
- ❌ Type 09 entries themselves → still excluded from CAPE
- ❌ Type 47 drawback, Type 08 informal, Type 23 TIB → still excluded

### Code changes

- Added `isFlaggedForReconciliation?: boolean` and `hasReconciliationEntry?: boolean` to `EntryForEligibility`
- Added `excluded_recon_filed` status (when flagged for recon AND Type 09 already on file)
- Added `cape_phase2` as a `FilingMethod`
- `getRoutingBucket` maps `excluded_recon_filed` to `not_applicable` (no current path; future phase will handle)

## 3. CAPE Phase 3 — CIT Orders Refunds for Finally-Liquidated Entries

**Status:** CONFIRMED court order July 17, 2026; CBP rollout in progress  
**Impact:** `checkEligibility()` updated — entries liquidated >180 days now route to `cape_phase3` (eligible) instead of `excluded_expired` (litigation only); `FilingMethod` gains `cape_phase3`

### What happened

On July 17, 2026, U.S. Court of International Trade Senior Judge Richard Eaton issued an order directing CBP to "reliquidate, without regard to IEEPA duties, any and all of Plaintiffs' entries that have been liquidated for more than 80 days." The order applies across approximately **3,700 consolidated IEEPA cases** before the court — effectively covering the vast majority of importers who paid IEEPA duties.

CBP was ordered to file a progress report by **August 4, 2026**. A closed settlement conference was scheduled for August 5, 2026. CBP had previously testified (June 9, 2026 hearing) that Phase 3 would be ready by end of July 2026.

### What Phase 3 covers

- **Finally-liquidated entries** = entries where liquidation is final AND the protest window has closed (liquidated >180 days ago from time of filing)
- Also covers entries liquidated 80–180 days ago per the CIT order wording ("more than 80 days")
- 80-day window is shared with Phase 1: entries liquidated ≤80 days ago continue via Phase 1/2

### Code change

Previously: entries liquidated >180 days ago → `status: "excluded_expired"`, `filingMethod: "litigation"` (no CAPE refund path)

Now: entries liquidated >180 days ago → `status: "eligible"`, `filingMethod: "cape_phase3"`, `needsReview: true` with caveat note

⚠️ **This is a significant semantic change** — entries previously flagged as ineligible (litigation only) are now flagged as eligible via Phase 3. The `needsReview: true` flag is set on all Phase 3 results to prompt verification with a customs attorney before relying on this path.

Entries liquidated 80–180 days ago retain the `protest` filing method (the formal protest route remains legally valid and is clearer for this window).

### Caveat

The Phase 3 CIT order covers "Plaintiffs' entries" in ~3,700 IEEPA cases. Universal CBP CAPE Phase 3 guidance for all importers (not just court plaintiffs) has been announced but the exact launch date and scope of the universal program is still being reported. All Phase 3 results in the calculator carry a `needsReview: true` flag and reviewNote directing users to verify with counsel.
