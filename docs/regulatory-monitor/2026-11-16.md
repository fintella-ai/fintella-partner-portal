### 2. CAPE Phase 3 Launched — CIT Plaintiffs Only (~October 2026)

CBP launched CAPE Phase 3 approximately October 6–26, 2026 (sources disagree on exact date). Phase 3 covers **finally liquidated entries** that fall outside the original 80-day CAPE Phase 1 window, **but only for importers with active Court of International Trade (CIT) lawsuits**. As of its launch, CBP had accepted ~477 Phase 3 declarations covering ~425,517 entries.

**What this means for the calculator:**
- Entries the calculator currently routes to `filingMethod: "litigation"` / `status: "excluded_expired"` (protest window >180 days) could qualify for CAPE Phase 3 processing — *if* the importer is an active CIT plaintiff.
- However, the calculator has no way to determine CIT plaintiff status from entry data alone.
- `EXCLUDED_ENTRY_TYPES` (08, 09, 23, 47) are **unchanged** — Types 09 (reconciliation) and 47 (drawback) remain excluded from all CAPE phases.
- The `FilingMethod` routing logic still correctly advises "CIT litigation only" for expired-protest entries — that's the prerequisite for Phase 3 anyway.

**Calculator impact: None required.** The current routing advice ("CIT litigation only") remains accurate for the general case. If Fintella advisors are working with clients who are already CIT plaintiffs, they should know Phase 3 processing is available to them.

### 3. CAPE Phase 2 — Already In Effect (June 29, 2026), No Code Changes Needed

Phase 2 (eff. June 29, 2026) accepts entries **flagged for reconciliation** (entry types 01, 02, 06) where the Type 09 reconciliation entry has not yet been filed. The Type 09 entries themselves remain excluded. No change to `EXCLUDED_ENTRY_TYPES`.

### 4. Section 122 Expired July 24, 2026 — Seed Data Already Correct

The 10% Section 122 global surcharge (HTS 9903.03.01) expired on its statutory 150-day limit on July 24, 2026. The seed file entry `S122-01` already reflects `endDate: "2026-07-23"`. No update needed.

**Replacement:** Section 301 tariffs at 10% or 12.5% (depending on country, based on forced-labor enforcement commitments) took effect July 24, 2026 for ~60 economies. These are **not IEEPA** and are prospective — outside the Feb 1, 2025 – Feb 23, 2026 IEEPA refund window. No impact on the calculator.

A CIT ruling on May 7, 2026 found Section 122 unlawful, but the Federal Circuit stayed that ruling. The 150-day statutory limit ran out before the appeal resolved.
