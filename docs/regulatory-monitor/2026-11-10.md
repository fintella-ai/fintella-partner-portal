### 1. Section 122 Tariffs (9903.03.xx) — EXPIRED as scheduled ✅

**Status: Confirmed expired July 24, 2026. No action needed.**

The 10% Section 122 global surcharge (Proclamation, Feb 23, 2026) expired at the end of its statutory 150-day maximum on July 23/24, 2026. Congress did not act to extend it. HTS codes 9903.03.01–9903.03.11 are all closed.

**What replaced it:** USTR proclaimed Section 301 "forced-labor" tariffs under the FLIP 301 investigation, effective 12:01 AM July 24, 2026 (FR notice July 23, 2026). These tariffs are **NOT IEEPA tariffs** and do not create new IEEPA refund claims. They are outside the scope of this calculator.

### 2. CAPE Phase 2 — Launched June 29, 2026 ✅

**Status: Live. No `EXCLUDED_ENTRY_TYPES` change needed.**

CBP launched CAPE Phase 2 on June 29, 2026. It covers entry types 01, 02, and 06 that are **flagged for reconciliation** but where the Type 09 Reconciliation Summary entry has NOT yet been filed. These entries can now go through CAPE before the Type 09 is submitted.

**Code impact:** The `EXCLUDED_ENTRY_TYPES` set (`"08", "09", "23", "47"`) remains correct. Phase 2 does not change which entry type codes are excluded — Type 09 (Reconciliation Summary Entry itself) is still excluded. Phase 2 only expanded eligibility for the **underlying** Type 01/02/06 entries before they receive a Type 09 filing. The calculator doesn't track the "flagged for reconciliation" flag in entry data, so no additional routing logic is needed.

### 3. CAPE Phase 3 — Launched October 6, 2026 ⚠️ ACTION TAKEN

**Status: Live since Oct 6, 2026. Code updated to reflect this.**

CBP launched CAPE Phase 3 on October 6, 2026. This phase covers **finally liquidated entries** where the importer of record was a named CIT plaintiff and provided their IOR number to CBP by **July 30, 2026**.

As of October 2, 2026, CBP had accepted approximately $136.6 billion in potential/certified refunds for processing. Approximately $122 billion (including interest) had been certified and transmitted to Treasury for payment. ~$1.3 billion remains on hold for importers who haven't provided ACH banking information.

**Code impact:** The `checkEligibility()` function previously routed entries with expired protest windows (liquidated > 180 days ago) to `filingMethod: "litigation"` with reason "CIT litigation only." This is still broadly correct — most importers with expired protest windows have no CAPE path. However, named CIT plaintiffs who registered by July 30, 2026 do have a CAPE Phase 3 path. 

**Changes made:**
1. Added `"cape_phase3"` to the `FilingMethod` union type
2. Updated the `excluded_expired` reason string to note CAPE Phase 3 availability for named plaintiffs
3. Added comment in `getRoutingBucket()` referencing Phase 3
