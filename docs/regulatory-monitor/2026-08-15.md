## 1. Section 122 → Section 301 Forced Labor Replacement (MAJOR — seed data updated)

### What changed

The Section 122 10% global import surcharge expired at 12:01 AM ET on July 24, 2026
(150-day statutory maximum under 19 U.S.C. § 2132). With no gap, USTR's final action
on 60 forced-labor Section 301 investigations took effect simultaneously.

The replacement is **NOT** an IEEPA tariff and is **NOT** part of the IEEPA/Section 122
refund system. It is documented in the seed file as context for the current tariff
landscape.

### Key details

| Attribute | Value |
|-----------|-------|
| Authority | Trade Act of 1974 § 301 (19 U.S.C. 2411) — USTR final action |
| Effective | Jul 24, 2026, 12:01 AM ET |
| HTS codes | `9903.05.20` – `9903.05.84` (each economy has its own heading) |
| Rate – Tier A | 10% ad valorem on 17 economies with partial forced-labor protections |
| Rate – Tier B | 12.5% ad valorem on 38+ other economies |
| Coverage | ~60 economies, ~99.4% of US imports by value |
| Notable exemptions | EU, Japan, South Korea, Switzerland, Taiwan: combined-duty structure not addl. ad valorem |
| In-transit exemption | Goods loaded before Jul 24, entered before Jul 28 → headings 9903.05.85–9903.05.92 |
| Stacking | Stacks with all other duties (Section 232, Section 301 China, etc.) |
| CBP guidance | CSMS #69326983 |

**Canada-specific:** heading `9903.05.29`. Separate Section 338 action adding 50% on
most Canadian goods also signed Jul 20, 2026, effective Aug 19, 2026 — that stacks
further. Not in scope of the TIE refund calculator.

### Section 122 status note

CIT held Section 122 tariffs unlawful in a May 7, 2026 ruling (balance-of-payments
deficit condition not satisfied). Government appealed. CBP continued collecting through
the statutory Jul 23 expiry despite the ruling. Refundability of Section 122 duties is
being litigated separately from the IEEPA refund process — watch this space.

## 2. CAPE Phase 2 Launched — Type 09 Reconciliation Entries Now Eligible (calculator updated)

### What changed

CAPE Phase 2 launched June 29, 2026. Phase 2 covers **reconciliation entries (entry
type 09)** where the underlying entry (types 01/02/06) is unliquidated or liquidated
within 80 days of the Phase 2 filing date AND the corresponding reconciliation (Type 09)
entry has not yet been filed.

The previous calculator excluded Type 09 entries entirely with `filingMethod: "none"`.
That is now wrong — Type 09 entries have a path via Phase 2.

### Code updated

- `src/lib/tariff-calculator.ts`:
  - Added `"cape_phase2"` and `"phase3_reliquidation"` to the `FilingMethod` union type.
  - Replaced single `EXCLUDED_ENTRY_TYPES` Set with `FULLY_EXCLUDED_ENTRY_TYPES` (08, 23, 47)
    and `CAPE_PHASE2_ENTRY_TYPES` (09). Kept the old `EXCLUDED_ENTRY_TYPES` alias for
    backward-compatibility.
  - Added new branch in `checkEligibility()` before the entry-type exclusion check:
    Type 09 entries now return `status: "eligible"` with `filingMethod: "cape_phase2"` and
    a descriptive reason explaining Phase 2 eligibility conditions.
  - Updated Type 08/23/47 exclusion reason text to be more precise (drawback-specific note
    for Type 47).

## 3. CAPE Phase 3 — Finally Liquidated Entries (calculator updated)

### What changed

On July 17, 2026, CIT Senior Judge Richard Eaton issued an order directing CBP to
**reliquidate "any and all of Plaintiffs' entries that have been liquidated for more than
80 days"** for importers with active CIT cases. Phase 3 covers finally-liquidated entries
(past the 180-day protest window) — the segment the calculator previously flagged as
`excluded_expired / filingMethod: "litigation"` with no near-term path.

CBP filed a progress report with the court on August 4, 2026. As of July 31, 2026:
75,000+ CAPE declarations submitted; $128.68B in refunds accepted for processing.
Phase 3 programming was expected by end of July 2026.

**Key limitation:** Phase 3 reliquidation per the court order applies **only to importers
with active CIT litigation**. Importers without an existing case must file new CIT
litigation (not administrative protest, as that window has closed).

The lead case is now **Freestyle World, Inc. v. United States** (CIT #25-series) after
Euro-Notions Florida voluntarily dismissed. Oral arguments scheduled for August 2026,
ruling expected shortly thereafter but certain to be appealed.

### Code updated

- `src/lib/tariff-calculator.ts`:
  - Updated the `daysRemaining < 0` branch in `checkEligibility()`: changed
    `filingMethod` from `"litigation"` to `"phase3_reliquidation"`, set
    `needsReview: true`, and updated reason/reviewNote to explain both Phase 3 (for
    active CIT litigants) and new CIT litigation (for those without a case).
  - Updated `getRoutingBucket()` to accept an optional `filingMethod` parameter:
    `phase3_reliquidation` routes to `"legal_required"` even when `status === "eligible"`.
