## Items for John's Review

1. **CAPE Phase 3 delay uncertainty**: One source (GHY, Oct 5) says CBP temporarily delayed Phase 3. Recommend checking CBP's current CSMS or the IEEPA refund page before advising clients.

2. **Section 301 rates not wired into calculator**: The new `rateType: "section301"` entries are informational only. `lookupCombinedRate()` doesn't have a breakdown bucket for `section301` — intentional since TIE only computes IEEPA refunds (historical). If Section 301 duty calculation is needed in the future, the breakdown interface needs a new bucket.

3. **`isCitPlaintiff` field not added**: The `EntryForEligibility` interface currently can't distinguish CIT plaintiffs. CAPE Phase 3 routing is mentioned in the `reason` string only — not reflected as a distinct `filingMethod: "cape_phase3"` in the returned result. Adding this flag would improve UX guidance but requires interface changes and consumer updates.

4. **Government appeal ongoing**: Federal Circuit No. 26-1898 could limit refund access for non-litigating importers on finally-liquidated entries. Monitor for ruling.
