### 4. Court of International Trade (CIT) Docket

Searched for new CIT rulings related to IEEPA tariffs.

**Finding (informational):** The CIT certified a non-litigant importer class in *Freestyle World v. United States* on October 8, 2026. This class covers importers who paid IEEPA duties but did not file their own CIT suits. The ruling is contested — the government has argued the court lacks authority to order refunds for non-plaintiffs, and the Federal Circuit (No. 26-1898) is reviewing the finally-liquidated entry reliquidation question.

**Impact on calculator:** None required today. The `isCitPlaintiff?: boolean` field added to `EntryForEligibility` in draft PR #1256 (October 8) already handles this case — class members qualify as effectively plaintiff-adjacent and can be flagged `isCitPlaintiff: true` to route to `cape_phase3`. The `reviewNote` in the `excluded_expired` branch already advises checking litigation status with counsel.

**Prior monitor note:** The October 8 and October 15 reports did not specifically mention the *Freestyle World* class certification. Flagged here for completeness. No separate code change warranted given the existing `isCitPlaintiff` coverage.

Source: [DWT: Trade Court Certifies Non-Litigant Importer Class](https://www.dwt.com/insights/2026/10/cit-certifies-ieepa-duty-refund-importer-class)

**Action required:** None — handled by existing draft PR #1256 logic.
