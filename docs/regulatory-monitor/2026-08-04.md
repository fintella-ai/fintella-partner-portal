## 2. Change Details

### Change 1 — Section 122 Expiration

**What happened**: The Section 122 global 10% surcharge expired by operation of law on July 24, 2026. The 150-day maximum is a hard statutory ceiling in 19 U.S.C. §2132; no extension is possible without an Act of Congress (no such bill advanced).

**Code change**: `prisma/seed-data/ieepa-tariff-rates.json`
- `S122-01.supersededBy`: `null` → `"S301-FL-01"`
- `S122-01.notes`: Updated to clearly state "EXPIRED Jul 24, 2026" and reference the Section 301 replacement

**Calculator impact**: None — the IEEPA refund calculator only processes entries between Feb 4, 2025 and Feb 23, 2026 (`IEEPA_START_DATE` / `IEEPA_END_DATE`). Section 122 is outside this window. The seed file update is for the rate database's completeness and audit trail.

---

### Change 2 — Section 301 Forced Labor Tariff (July 24, 2026)

**What happened**: USTR's final action across 60 forced-labor Section 301 investigations took effect at 12:01 AM ET July 24, 2026 — the same minute Section 122 expired. This is a two-tier tariff:

| Tier | Rate | Coverage |
|------|------|----------|
| Standard | 10% | ~22 economies that ban forced-labor imports, committed via bilateral Agreement on Reciprocal Trade, or operate a partial regime |
| Elevated | 12.5% | 38 economies including China, Vietnam, Thailand, Brazil, Russia |

**Key facts**:
- Authority: Section 301 of the Trade Act of 1974 — NOT IEEPA
- HTS Chapter 99 codes: `9903.05.20` through `9903.06.21`
- Exemptions: USMCA goods (Canada/Mexico), CAFTA-DR textile/apparel
- In-transit exclusion: goods loaded pre-July 24 and entered before July 28 exempt
- No statutory expiration date — only legislation, litigation, or negotiation removes it
- CBP implementation: CSMS #69326983

**Code change**: Added two new entries to `prisma/seed-data/ieepa-tariff-rates.json`:
- `S301-FL-01`: Standard 10% tier
- `S301-FL-02`: Elevated 12.5% tier (China, Vietnam, Thailand, Brazil, Russia, etc.)

**Calculator impact**: None — these are Section 301 duties, not IEEPA. The IEEPA refund calculator's `checkEligibility()` function continues to gate on `IEEPA_START_DATE`/`IEEPA_END_DATE` (Feb 1, 2025 – Feb 23, 2026), so Section 301 entries are automatically outside scope. The seed entries are flagged with `NOTE: This is NOT an IEEPA tariff` in their notes field. The `lookupCombinedRate()` breakdown interface now includes `section301?: number` to surface these rates in UI contexts.

### Change 3 — CAPE Phase 2 (June 29, 2026)

**What happened**: CBP deployed CAPE Phase 2 on June 29, 2026, expanding the automated refund system to reconciliation-flagged consumption entries (Types 01, 02, 06) **where the Type 09 reconciliation summary entry has not yet been filed**. Scale: 2.8M additional entries, $28.7B in additional IEEPA duties now eligible.

**Phase 2 eligibility requirements** (additive to Phase 1 requirements):
1. Entry type must be 01, 02, or 06
2. Entry must be flagged for reconciliation
3. The associated Type 09 reconciliation entry must NOT yet have been filed
4. Entry must still be unliquidated or within the 80-day post-liquidation window
5. If reconciliation deadline is <30 days away, CBP advises filing Type 09 first

**Still excluded from all phases**: Type 47 drawback, Type 08, Type 23, Type 09 entries themselves, and reconciliation-flagged entries where Type 09 has already been filed.

**Code changes** to `src/lib/tariff-calculator.ts`:
- `FilingMethod` type: added `"cape_phase2"` (reconciliation-flagged unliquidated/80-day entries where Type 09 not filed)
- `EntryForEligibility` interface: added `isReconciliationFlagged?: boolean` and `type09Filed?: boolean`
- `checkEligibility()`:
  - New step 4a: if `isReconciliationFlagged && type09Filed` → `excluded_type` (CAPE cannot accept)
  - `isCapePhase2` flag propagates to `filingMethod` in both the liquidated-within-80-days and unliquidated paths
- `CAPE_PHASE1_LIQUIDATION_WINDOW_DAYS` comment updated to mention Phases 1 and 2

**Code changes** to `src/lib/tariff-risk-score.ts`:
- `FILING_RISK` record: added `cape_phase2: 0` (same automated-CAPE risk level as Phase 1)

**CAPE Phase 3 note** (no code change): Phase 3 (finally-liquidated entries, > 180 days after liquidation) launched approximately July 31, 2026, but is currently restricted to importers with active CIT cases. The code's existing `filingMethod: "litigation"` routing for entries with expired protest windows remains accurate; Phase 3 is a processing mechanism for CIT litigants, not a new eligibility category. CBP Phase 3 progress report due today (August 4, 2026). The `FilingMethod` JSDoc comment has been updated to note Phase 3's existence.
