## Actionable Change: CAPE Phase 3 — Finally-Liquidated Entries

**Source:** Thompson Hine, Sept 2026: [CBP Confirms October 6, 2026 Launch of Phase 3 of the IEEPA Tariff Refund Process](https://www.thompsonhine.com/insights/cbp-confirms-october-6-2026-launch-of-phase-3-of-the-ieepa-tariff-refund-process/)  
**Source:** InternationalTradeInsights.com, Sept 2026: [CBP States CAPE Phase 3 Will Deploy on October 6, 2026](https://www.internationaltradeinsights.com/2026/09/cbp-states-cape-phase-3-will-deploy-on-october-6-2026/)

### What changed

CBP launched CAPE Phase 3 on October 6, 2026. Phase 3 allows importers to file CAPE declarations for **finally-liquidated entries** — those that were liquidated more than 80 days ago AND outside the 180-day protest window (i.e., the entries the calculator previously classified as `litigation`-only).

**Key constraints (Phase 3 scope is narrow):**
- Only available to importers who have an **active case filed at the Court of International Trade**
- Importer of record (IOR) must have been submitted to CBP by July 30, 2026 (late submitters get separate instructions)
- Phase 3 does NOT apply to non-plaintiff importers — they still require new CIT litigation
- CIT class certification issued October 8, 2026 (*Freestyle World* v. United States) covers non-litigant importers, but **no injunction has issued yet** and no Phase 3 access for the class — parties' scheduling order due October 22, 2026

### What was updated

**`src/lib/tariff-calculator.ts`:**

1. Added `"cape_phase3"` to the `FilingMethod` type with updated JSDoc
2. Updated the `daysRemaining < 0` branch in `checkEligibility()`:
   - Was: `filingMethod: "litigation"`, generic reason
   - Now: `filingMethod: "cape_phase3"`, updated reason text, `needsReview: true`, and a `reviewNote` explaining the Oct 6 launch, the CIT-plaintiff requirement, and the class certification status
3. Routing bucket for `excluded_expired` entries remains `legal_required` — correct, since Phase 3 still requires legal involvement (CIT plaintiff status)

### What was NOT changed (no action needed)

- `EXCLUDED_ENTRY_TYPES` (`["08", "09", "23", "47"]`): Phase 3 covers Type 01/02/06 finally-liquidated entries. Type 09 (reconciliation entries themselves) and Type 47 (drawback) remain excluded — CBP guidance is unchanged on these.
- Seed data (`ieepa-tariff-rates.json`): Section 122 `S122-01` already has `"endDate": "2026-07-23"` — correctly marked expired. No rate changes.
