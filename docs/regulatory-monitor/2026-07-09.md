### 2. CAPE: Warehouse entries (Types 21/22) excluded effective July 7, 2026

**Source**: CBP CSMS #69127837 — "UPDATE – Consolidated Administration and Processing of Entries (CAPE) for IEEPA Refunds – Warehouse Entries"

**What changed**: Effective July 7, 2026, CBP no longer accepts entry types 21 (warehouse entries) and 22 (re-warehouse entries) on CAPE declarations. Warehouse **withdrawals** (Types 31, 32, 34, 38) continue to be accepted, because IEEPA duties were collected at withdrawal, not at the time goods entered the warehouse.

**Update made**:
- Added `"21"` and `"22"` to `EXCLUDED_ENTRY_TYPES` in `src/lib/tariff-calculator.ts`
- The `checkEligibility()` function now returns `excluded_type` with a message directing users to file on their withdrawal entry (Type 31/32/34/38)
- Updated `capePhase1.eligibleEntryTypes` in the seed file: moved 21/22 from `included` to `excluded`; added Types 31/32/34/38 to the `included` list (they were implicitly eligible but not documented)

### 3. CAPE Phase 2 launched June 29, 2026

**Source**: CBP CSMS #69066837 (deployment, June 29, 2026); CSMS #69035485 (guidance, June 23, 2026)

**What changed**: CAPE Phase 2 went live on June 29, 2026. It adds eligibility for entries of type 01, 02, and 06 that are **flagged for reconciliation** (reconciliation pending) — provided the reconciliation entry (Type 09) has **not yet been filed**.

Critical sequencing rule: importers must submit the CAPE declaration BEFORE filing the Type 09 reconciliation entry. Filing Type 09 first permanently locks those underlying entries out of CAPE.

**What remains excluded**: Type 09 reconciliation summaries themselves; Type 47 drawback entries; Types 21/22 (see above).

**Update made**: Added `capePhase2` documentation block to `prisma/seed-data/ieepa-tariff-rates.json`. No change to `checkEligibility()` for Phase 2 reconciliation entries — the existing code already allows Types 01/02/06 through correctly (Type 09 itself remains excluded by `EXCLUDED_ENTRY_TYPES`). The sequencing risk is a business-process concern, not a calculator eligibility concern.
