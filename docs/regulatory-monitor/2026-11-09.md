## Findings

### 1. ✅ CAPE Phase 2 — LIVE since June 29, 2026 (gap in calculator — FIXED this run)

**Source:** CBP CSMS #69066837; https://www.tariffstool.com/guides/cape-phase-2-launches-june-29-2026

CAPE Phase 2 launched June 29, 2026. It covers entry types 01, 02, and 06 that CBP has flagged for reconciliation where the Type 09 reconciliation entry has not yet been filed. CBP estimated ~2.8 million entries (~$28.7B in refunds) in scope.

**Calculator gap found:** `FilingMethod` only had `cape_phase1` as an automated CAPE path. Entries of types 01/02/06 flagged for reconciliation in the 80–180 day post-liquidation window were being classified as `"protest"` when they should be `"cape_phase2"`.

**Changes made in this PR:**
- Added `cape_phase2` to `FilingMethod` type (`src/lib/tariff-calculator.ts:38`)
- Added `isFlaggedForReconciliation?: boolean` to `EntryForEligibility` interface
- Updated `checkEligibility()` routing: reconciliation-flagged entries in the 80–180 day window → `cape_phase2` (instead of `protest`)
- Updated `EXCLUDED_ENTRY_TYPES` comment to clarify that Type 09 entries are excluded, but entries of other types FLAGGED FOR reconciliation are Phase 2 eligible

- Review the Phase 2 deadline behavior: Phase 2 entries still face the 180-day protest deadline, same as Phase 1 and protest (no special extension)
