## 2. CBP Bulletins (cbp.gov) — ACTIONABLE

**Checked:** CSMS messages about IEEPA, CAPE, duty refunds, Chapter 99 HTS.

### CAPE Phase 2 — Deployed June 29, 2026 ✅ (CODE UPDATED)

CBP published CSMS #69035485 (June 23, 2026) and CSMS #69066837 (June 29, 2026 — deployed) confirming Phase 2 of CAPE.

**What changed:**
- CAPE now accepts entry types **01, 02, and 06** that carry the ACE **reconciliation flag** when **no Type 09 reconciliation entry has yet been filed**
- Phase 1 excluded these entries; Phase 2 accepts them with the same 80-day liquidation window
- **Critical filing sequence**: CAPE declaration **must be filed before** the Type 09 reconciliation entry. If Type 09 is filed first, the underlying entries are locked out of Phase 2 and deferred to a future CAPE phase (timeline unknown)
- Entries with a Type 09 already filed are NOT covered by Phase 2 — future CAPE phase pending

**Not included in Phase 2:**
- Entry Type 47 (drawback) — still excluded
- Entry Type 09 itself (the reconciliation entry) — still excluded
- Entry types 01/02/06 where a Type 09 has already been filed — deferred to future phase

**Code change made:** `src/lib/tariff-calculator.ts`
- Added `"cape_phase2"` to `FilingMethod` union type
- Added `isFlaggedForReconciliation?: boolean` and `hasType09Filed?: boolean` fields to `EntryForEligibility`
- New `checkEligibility()` logic (step 4): reconciliation-flagged entries routed to Phase 2 or excluded with `"excluded_recon_phase2"` status
- Steps 7/8: filing method assigned `"cape_phase2"` vs `"cape_phase1"` based on reconciliation flag

**Sources:**
- https://content.govdelivery.com/accounts/USDHSCBP/bulletins/41d65dd (CSMS #69035485)
- https://content.govdelivery.com/bulletins/gd/USDHSCBP-41de055 (CSMS #69066837 — deployed)

## 5. Section 122 Status — EXPIRING JULY 24, 2026 ⚠️

**Existing seed data is correct:** `S122-01` in `ieepa-tariff-rates.json` already has `endDate: "2026-07-23"` (last effective day) — no rate data change required.
