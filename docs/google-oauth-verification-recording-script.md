## VIDEO 1: OAuth Consent Screen Workflow (~2 min)

> Google wants: "A link to a demo video showing the OAuth workflow"

- **LEFT:** Navigate to `fintella.partners/admin/settings`
- Scroll to the **Google Calendar** card
- Hover/highlight the "Not Connected" status badge
- Pause briefly so the reviewer sees the starting state

- **LEFT:** Click the gold **"Connect Google Calendar"** button

- **FULL SCREEN on the consent screen** (or keep side-by-side, reviewer needs to read this)

- **LEFT:** Browser redirects to `fintella.partners/admin/settings?google_calendar=connected`

## Troubleshooting

- **"Not connected" after clicking Allow:** Check that `GOOGLE_OAUTH_CLIENT_ID` and `GOOGLE_OAUTH_CLIENT_SECRET` are set in Vercel env vars
- **Consent screen shows "unverified app" warning:** This is expected — that's what we're trying to get verified
- **No Meet recordings in Drive:** Record a quick Google Meet call first, wait ~30 min for Google to process the recording
- **Gmail shows 0 messages:** Make sure the connected Google account has emails — send yourself a test email first
- **Licensing API returns nothing:** Account must be on a Google Workspace plan (not personal Gmail)
