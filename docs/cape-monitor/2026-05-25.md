## Summary

Five significant operational updates detected since the April 20 Phase 1 launch. No changes to entry type eligibility, CSV format, filer eligibility rules, or ABI support status. `tariff-calculator.ts` is unchanged. All updates are informational/knowledge-base.

## 1. Rejection Rate — Significantly Higher Than CBS News Baseline

**Previous known rate:** ~15% rejection (CBS News, cited in CLAUDE.md)  
**Current data:**

| Metric | Value | Source |
|---|---|---|
| First-pass acceptance (as of April 26) | ~21% | tariffstool.com |
| Filings passing first validation | ~63% | C.H. Robinson (May 2 advisory) |
| Entries accepted for duty removal (May 11) | 15,123,221 | CBP CSMS / Krieger Worldwide |
| Entries liquidated/reliquidated (May 11) | 8,338,081 | CBP CSMS / Krieger Worldwide |
| Estimated refund + interest | ~$35.46 billion | CBP CSMS |

The ~15% figure reflected prototype testing, not live volume. In production:
- ~37% of entries are currently failing validation on first submission
- ~79% of filings are rejected on first pass and require resubmission  
- Files that pass validation eventually clear, so the effective final acceptance rate is improving as filers correct and resubmit

**Broker impact:** First-submission success rate is much lower than anticipated. Clients should expect at least one resubmission cycle.

## 2. ACH Refund Payments — Active as of May 12, 2026

CBP announced on May 4 (CSMS #68536553) that Treasury would begin issuing ACH payments as of May 12, 2026. **Phase 1 refunds are now actively hitting bank accounts.**

Key enrollment note: **ACH enrollment for duty payments ≠ ACH enrollment for refunds.** Filers must enroll a separate "refund" bank account in the ACE Portal under the Importer sub-account. As of May 11, 1,880 consolidated refunds are blocked awaiting missing ACH enrollment.

Refund processing timeline from acceptance:  
- Accepted → "Sent to Treasury" → "Treasury Issued" → bank account (ACH)  
- Total lag: 60-90 days from acceptance (unchanged)

## 3. New ACE Report Secondary Statuses (REV-615)

ACE REV-615 (Trade CAPE Detail Refund Report, added April 20) now exposes four secondary statuses for monitoring individual refunds after acceptance:

| Status | Meaning |
|---|---|
| `Sent to Treasury` | CBP transmitted refund instruction to Treasury |
| `Treasury Issued` | Treasury disbursed the payment |
| `Funds Diverted` | Payment offset by a netting/debt diversion (19 CFR §159.1 / §24.72) |
| `Check/ACH Returned` | Bank rejected payment — missing or incorrect ACH enrollment |

REV-603 and REV-613 remain unchanged; REV-613 specifically flags the 1,880 ACH-missing cases.

## 6. New Rejection Causes Beyond Known Error Codes

The five known CBP error codes remain (ENTRY ON DRAWBACK, PROTEST ON ENTRY, ENTRY SUMMARY UNDER REVIEW, NO IEEPA HTS ON ENTRY, STATEMENT PROCESSING NOT COMPLETE). Additional rejection patterns identified in live Phase 1 operations:

**File-level rejections (entire declaration rejected — requires full resubmission):**
- Incorrect file format or missing `Entry Number` header row
- Non-UTF-8 encoding or BOM characters in CSV

**Entry-level rejections (only affected entries rejected — partial resubmission):**
- HTS classification mismatch — entry's HTS code has no IEEPA tariff column
- Valuation inconsistency — entered value vs. CBP calculated value discrepancy
- Country-of-origin discrepancy — COO on entry vs. CBP records
- Section 232/301 stacking error — duplicate tariff overlay at liquidation
- Entry number formatting — filer code (first 3 chars) must match ACE filer code on file

**Pre-filing issues (prevent acceptance entirely):**
- Outdated ACE credentials tied to former employees — file CBP Form 5106 to update IOR record before submission
- ACH enrollment missing or enrolled only for duty payments (not refunds) — separate ACE Importer sub-account enrollment required
