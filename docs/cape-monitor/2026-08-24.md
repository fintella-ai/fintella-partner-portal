## 1. CAPE Phase 2 Launched — June 29, 2026

**Source:** CSMS #69066837; [CBP GovDelivery bulletin](https://content.govdelivery.com/accounts/USDHSCBP/bulletins/41de055); [Thompson Hine SmarTrade](https://www.thompsonhinesmartrade.com/2026/06/cbp-confirms-june-29-2026-ieepa-tariff-refund-process-phase-2-launch/)

### What changed
CBP deployed CAPE enhancements on June 29, 2026, to accept base entries **flagged for reconciliation** (entry types 01, 02, 06) for which the reconciliation entry (Type 09) has **not yet been filed**.

### Eligibility constraints
- Limited to **unliquidated entries** and entries **within 80 days of liquidation**.
- Entries flagged for reconciliation where the Type 09 reconciliation entry **has already been filed** are still excluded.
- **Type 09 (reconciliation entry itself) remains excluded** — only the base entries (01/02/06 with no 09 on file) are eligible.
- Once a flagged base entry is accepted on a CAPE Declaration, the trade may file the reconciliation entry separately; CAPE removes IEEPA duties from the base entry before the reconciliation calculation.

### Code impact
No change to `EXCLUDED_ENTRY_TYPES` required (Type 09 remains excluded; base types 01/02/06 were never excluded). Updated code comments to document Phase 2 scope and date. The `EntryForEligibility` interface does not currently have a `isFlaggedForReconciliation` boolean; if CBP's ACE validation creates a separate flow for flagged entries, adding that field may be warranted in a follow-up.

## 2. Warehouse Entry Types 21 & 22 Excluded — Effective July 7, 2026

**Source:** CSMS #69127837; [CBP GovDelivery bulletin](https://content.govdelivery.com/bulletins/gd/USDHSCBP-41ece9d?wgt_ref=USDHSCBP_WIDGET_2); [M.E. Dey summary](https://www.medey.com/cape-phase-2-is-live-here-is-what-that-means-for-ieepa-refunds/)

### What changed
Effective **July 7, 2026**, warehouse entries (Types 21 and 22) are **no longer accepted** on a CAPE Declaration.

Warehouse withdrawals (Types **31, 32, 34, 38**) continue to be accepted; refunds are processed upon re-liquidation of the associated warehouse entry.

### Edge case (gap window)
Importers who had Types 21 or 22 accepted on a CAPE Declaration **between April 20 and July 6, 2026** without a corresponding warehouse withdrawal submission will **not** receive an IEEPA refund on those entries under the current framework. They must file a **separate CAPE Declaration** covering the warehouse withdrawals on which IEEPA duties were paid.

### Code impact
**Added "21" and "22" to `EXCLUDED_ENTRY_TYPES`** in `src/lib/tariff-calculator.ts`. Updated the per-type reason string for Types 21/22 to direct filers to submit warehouse withdrawal entries instead.

## 3. Rejection Rate Update

**Source:** [Tariffstool.com analysis](https://www.tariffstool.com/guides/cape-rejection-rate-15-percent-why-claims-fail); [WWD sourcing journal](https://wwd.com/sourcing-journal/trade/cbp-ieepa-tariff-refund-cape-ace-cit-importers-entries-1238934302/)

- **Declaration-level rejection rate:** ~15% (CBP-confirmed; consistent with prior monitoring baseline)
- **Entry-level rejection rate:** ~19% — of the 11,222,927 entries passing file validation, ~19% were rejected on secondary criteria
- The gap between declaration-level and entry-level rates means some declarations with mixed-eligibility entry sets are partially accepted

### Known rejection error codes (unchanged)
- `ENTRY ON DRAWBACK`
- `PROTEST ON ENTRY`
- `ENTRY SUMMARY UNDER REVIEW`
- `NO IEEPA HTS ON ENTRY`
- `STATEMENT PROCESSING NOT COMPLETE`

### New silent rejection pattern identified
Customs brokers filing on behalf of **multiple Importers of Record (IOR)** in a single CAPE CSV are experiencing **silent partial rejections**: CAPE processes only the first IOR's entries and ignores remaining IOR entries without flagging an error. Each CAPE Declaration CSV must contain entries for a **single IOR only**.

**No code impact** — the CSV format spec is unchanged. This is an operational advisory for the broker dashboard / user guidance.

## 4. ACE Report ES-022 Added

**Source:** CSMS bulletin (May 4, 2026); [RIM Logistics summary](https://www.rimlogistics.com/cbp-provides-multiple-ace-reports-to-monitor-cape-refund-claims/)

A new ACE report, **ES-022 (CAPE Entry Summary Report)**, was added alongside the existing suite:

| Report | Purpose |
|--------|---------|
| **ES-022** *(new)* | Links entry, CAPE declaration, and refund numbers — primary tracking view |
| REV-603 | Trade Refund Report — tracks declarations with refund secondary statuses after Treasury receipt |
| REV-615 | CAPE Detail Refunds Report — entry summary data for declarations sent to Treasury |
| REV-613 | ACH Rejected Refunds — refunds rejected due to incomplete ACH enrollment |
| ES-701/ES-702 | Liquidation notices (unchanged) |

**No code impact.** Consider surfacing ES-022 in the admin dashboard report documentation.
