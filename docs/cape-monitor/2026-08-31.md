## 2. CAPE Phase 2 — CONFIRMED LIVE (June 29, 2026)

### What changed
CBP expanded CAPE on June 29, 2026 to accept **reconciliation-flagged parent entries** where the Type 09 reconciliation entry has **not yet been filed**.

**Newly eligible entry category:**
- Entry types **01, 02, 06** (consumption, informal, foreign trade zone) that carry a reconciliation flag and for which the Type 09 reconciliation entry has NOT been filed

**Conditions for Phase 2 eligibility:**
- Entry is unliquidated, OR liquidated within the 80-day CAPE window (same as Phase 1)
- The Type 09 reconciliation entry itself has NOT yet been filed

### Still excluded (Phase 1 and Phase 2)
| Type | Description | Status |
|------|-------------|--------|
| 08 | Duty Deferral | Still excluded |
| 09 | Reconciliation entry (the Type 09 itself) | Still excluded |
| 23 | Temporary Importation under Bond (TIB) | Still excluded |
| 47 | Drawback | Still excluded |

No CAPE Phase 3 announcement found.

### Impact on `src/lib/tariff-calculator.ts`
- `EXCLUDED_ENTRY_TYPES` array **unchanged** — 08/09/23/47 remain excluded
- New `FilingMethod` value `"cape_phase2"` added for reconciliation-flagged eligible entries
- New `isReconciliationFlagged?: boolean` field added to `EntryForEligibility`
- `checkEligibility()` now routes reconciliation-flagged entries to `cape_phase2` (or `protest` if liquidated 80–180 days ago)
- `FILING_RISK` in `tariff-risk-score.ts` updated: `cape_phase2: 0` (same low risk as Phase 1)
- Comments throughout updated to reflect Phase 2 launch

## 5. CAPE Rejection Rate

**Last known**: ~15% (CBS News, confirmed by multiple trade publications as of mid-2026)

**Top rejection causes (accounts for ~79% of all rejections):**
1. HTS classification mismatch (CAPE HTS ≠ entry summary HTS)
2. Entry on drawback (ENTRY ON DRAWBACK error code)
3. Protest already filed on entry (PROTEST ON ENTRY error code)
4. Entry summary under review (ENTRY SUMMARY UNDER REVIEW error code)

No new rejection trends or CAPE system outages reported since prior monitoring.
