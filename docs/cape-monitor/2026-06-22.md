## 🔴 ACTIONABLE CHANGE — CAPE Phase 2 (Type 09 Reconciliation, June 29, 2026)

**Source**: GHY Trade Compliance (https://www.ghy.com/trade-compliance/cbp-cape-reconciliation-ieepa-tariff-refunds-june-29/); CBP filing to CIT (June 9, 2026); Thompson Hine SmarTrade

### What changed

CBP announced to the U.S. Court of International Trade on June 9, 2026 that it is expanding CAPE to cover reconciliation entries. **CAPE Phase 2 is scheduled to launch June 29, 2026** — one week from today.

**Phase 2 scope:**
- Entry Type 09 (Reconciliation Summary) entries that are unliquidated OR liquidated within 80 days of the Phase 2 filing date
- Entries *flagged for reconciliation* (Types 01, 02, 06) where **no Type 09 has been filed** at the time of CAPE acceptance
- CBP estimated ~2.8 million additional entries worth ~$28.7B in refunds

**Key limitation:**
Entries from before approximately May 31, 2025 on a standard 314-day liquidation cycle will have liquidated more than 80 days before June 29, 2026 and fall outside Phase 2 scope. Do not assume Phase 2 will capture the earliest IEEPA entries.

**Condition for eligibility:**
The reconciliation (Type 09) entry must NOT have been filed at the time of CAPE acceptance. Brokers who have already filed a Type 09 cannot use Phase 2 for those entries.

### Code change made

Updated `src/lib/tariff-calculator.ts`:
- Added `"cape_phase2"` to `FilingMethod` type
- Removed `"09"` from `EXCLUDED_ENTRY_TYPES` set (now contains only `["08", "23", "47"]`)
- Added Type 09 special case in `checkEligibility()`:
  - If liquidated >180 days (protest expired): returns `excluded_expired` / `litigation`, noting Phase 3 may apply for 1581(i) litigants
  - Otherwise: returns `eligible` / `cape_phase2` with `needsReview: true` and a note about the Phase 2 filing condition

## 🟡 WATCH ITEM — CAPE Phase 3 (Finally-Liquidated Entries, est. late July 2026)

**Source**: Thompson Hine SmarTrade, BDO, Holland & Knight

CBP plans to launch Phase 3 for "finally liquidated" entries (those past the 180-day protest window) by end of July 2026. **Critical caveat**: Phase 3 will only process refunds for importers who filed Section 1581(i) court actions. General importers without a court action will NOT receive Phase 3 refunds through CAPE.

Additionally, the Government filed a Federal Circuit appeal on June 3, 2026 challenging the CIT's order requiring universal IEEPA refunds. The Government's position: it lacks legal authority to refund finally-liquidated entries without an importer-specific court judgment.

**Impact on `litigation` routing path**: No code change made. The `litigation` filingMethod is still correct for entries with an expired protest window. The Phase 3 caveat (1581(i) requirement) is now noted in the Type 09 exclusion reason string in `checkEligibility()`. Types 08, 23, 47 entries that have expired protest windows remain `excluded_expired` / `litigation` as before.

**Action needed when Phase 3 launches**: Reassess whether to add a `cape_phase3` FilingMethod and update the `excluded_expired` reason string for non-reconciliation entries too.

## CAPE rejection rate update

Prior baseline: ~15% (CBS News, reported at launch)
Current status: **~15% rejection rate confirmed** as of May 26, 2026. CBP reported 157,402 declarations filed, with ~70% passing initial file validation and ~15.9 million entries passing entry validation.

CBP published a detailed CAPE error code list (new since launch). Top rejection causes (79% of rejections):
1. HTS classification mismatch
2. Valuation inconsistency
3. Country-of-origin discrepancy
4. Section 232/301 stacking errors

Error codes from Phase 1: `ENTRY ON DRAWBACK`, `PROTEST ON ENTRY`, `ENTRY SUMMARY UNDER REVIEW`, `NO IEEPA HTS ON ENTRY`, `STATEMENT PROCESSING NOT COMPLETE` — all still active.
