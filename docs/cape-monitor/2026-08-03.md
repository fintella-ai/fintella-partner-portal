# CAPE/ACE Monitor Report — 2026-08-03

## Summary

**Significant changes found.** Two CAPE rule changes since the previous monitoring run affect `tariff-calculator.ts`. Code updated in this session. See PR for diff.

---

## Changes Detected

### 1. Warehouse entries (Types 21 and 22) excluded — effective July 7, 2026

CBP issued a CSMS bulletin removing warehouse entries from CAPE eligibility effective July 7, 2026. Entry Types 21 and 22 will no longer be accepted on CAPE Declarations.

**Code change**: Added `"21"` and `"22"` to `EXCLUDED_ENTRY_TYPES` in `src/lib/tariff-calculator.ts`.

### 2. CAPE Phase 2 launched — June 29, 2026

CBP launched CAPE Phase 2 on June 29, 2026. Key additions:
- Reconciliation-flagged consumption entries (Types 01, 02, and 06) where **no Type 09 reconciliation entry has been filed** are now accepted.
- CAPE separates the IEEPA duty refund from the flagged entry *before* the reconciliation entry is filed, so the two don't collide.
- The 80-day liquidation window applies the same as Phase 1.
- Type 09 itself (the reconciliation entry) remains excluded from direct CAPE filing.

**Code change**: Added `reconciliationFlagged?: boolean` to `EntryForEligibility` interface; added `"cape_phase2"` to `FilingMethod` union; updated `checkEligibility()` to route reconciliation-flagged entries to `filingMethod: "cape_phase2"` with appropriate reason strings.

## CAPE Phase 3 — Watch Item

CBP confirmed at the June 9, 2026 CIT hearing that Phase 3 is targeted for end of July 2026 and will cover **finally liquidated entries** (those liquidated more than 80 days before the filing date). This is the largest remaining excluded category.

Phase 3 is expected to address some subset of:
- Historically liquidated entries beyond the 80-day window
- Potentially Type 08 Duty Deferral, Type 23 TIB, and eventually Type 47 Drawback (future phases)

**No confirmation of Phase 3 launch found as of this monitoring run.** Monitor next run should search specifically for Phase 3 live status. If confirmed launched:
- Remove the `CAPE_PHASE1_LIQUIDATION_WINDOW_DAYS` 80-day restriction for qualifying finally-liquidated entries
- Add `"cape_phase3"` to `FilingMethod` union
- Update protest/litigation routing logic accordingly
