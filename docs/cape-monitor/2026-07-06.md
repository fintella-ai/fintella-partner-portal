## Change 1 — CRITICAL: Warehouse Entry Types 21 & 22 Removed (effective July 7, 2026)

**Source**: CBP CSMS bulletins; confirmed via multiple trade publications  
**Effective**: July 7, 2026 (tomorrow)

CBP is removing warehouse entry types 21 and 22 from CAPE eligibility effective July 7, 2026. Any warehouse entry submitted on a CAPE Declaration on or after that date will be rejected with `ENTRY TYPE NOT ALLOWED`.

**Key details**:
- Entry Types 21 and 22 (warehouse entries) were accepted April 20 – July 6, 2026 only
- Warehouse **withdrawal** types (31, 32, 34, 38) remain eligible — IEEPA duties are assessed at withdrawal, not entry, so these are the correct filing vehicle
- Importers who filed Types 21/22 entries between April 20 and July 6 and did not include the corresponding withdrawal entries need to submit a new CAPE Declaration covering the withdrawal entries (31/32/34/38)
- No grace period; rejected with existing error code

**Impact on calculator**: Added "21" and "22" to `EXCLUDED_ENTRY_TYPES` with a specific reason string directing importers to the correct withdrawal types.

---

## Change 2: CAPE Phase 2 Live — Reconciliation-Flagged Entries Now Eligible (June 29, 2026)

**Source**: CSMS # 69035485; Diaz Trade Law, Thompson Hine SmarTrade, GEODIS  
**Effective**: June 29, 2026 (already live)

CBP deployed CAPE Phase 2, allowing importers to include entries flagged for reconciliation (entry types 01, 02, 06) where the Type 09 reconciliation entry has not yet been filed.

**Key details**:
- Phase 2 uses the same 80-day CAPE window as Phase 1 (unliquidated or liquidated within 80 days)
- **Critical filing sequence**: the CAPE Declaration MUST be filed BEFORE the Type 09 reconciliation entry. Filing the reconciliation entry first permanently locks the underlying entries out of CAPE Phase 2 and forfeits the automated refund path
- CAPE strips IEEPA duties from the flagged entries prior to the Type 09 filing, separating the IEEPA refund from reconciliation calculations
- Entries already subject to a filed Type 09 reconciliation are NOT eligible via Phase 2

**Impact on calculator**:
- Added `isReconciliationFlagged?: boolean` field to `EntryForEligibility`
- Added `"cape_phase2"` filing method
- Added `applyReconciliationPhase2Flag()` helper that upgrades Phase 1 results to Phase 2 when the flag is set, and adds a review note about the mandatory filing sequence

## Change 3 (Background): Government Appeals CIT IEEPA Refund Order

**Source**: Holland & Knight (June 2026)

The government has appealed the Court of International Trade order mandating IEEPA refunds. The appeal does not currently affect CAPE operations — CBP continues processing refunds per its existing guidance. No calculator changes required; situation to monitor.

## Current Rejection Rate

~15% (CBS News; originally reported). More recent sources suggest ~21% pass rate on first submission, with ~70% of declarations passing initial file validation. Dominant rejection reasons: HTS classification mismatches, valuation inconsistencies, country-of-origin discrepancies, Section 232/301 stacking errors (account for ~79% of rejections). Silent rejections still occur when a CSV contains entries from multiple Importers of Record — CAPE processes the first IOR only without flagging the error.
