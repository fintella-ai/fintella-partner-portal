## ✅ Findings & Actions Taken

### 1. CAPE Phase 2 — Reconciliation Entries Now Eligible (June 29, 2026)

**What changed**: CBP launched CAPE Phase 2 on June 29, 2026. Type 01, 02, and 06 entries *flagged for reconciliation* where the reconciliation summary (Type 09) has **not yet been filed** are now eligible via CAPE Phase 2.

**How it works**: CBP separates the IEEPA duty refund from the reconciliation calculation before the Type 09 entry is filed. The Type 09 reconciliation summary itself is still excluded from CAPE directly.

**Eligibility window**: Same 80-day liquidation window as Phase 1.

**Source**: Thompson Hine SmarTrade (June 2026); CBP IEEPA Duty Refunds page; multiple trade law publications.

**Code change**:
- Added `isReconciliationFlagged?: boolean` field to `EntryForEligibility` interface
- Added `"cape_phase2"` to the `FilingMethod` type
- Added Phase 2 routing logic in `checkEligibility()`: entries with `isReconciliationFlagged: true` route to `filingMethod: "cape_phase2"`
- Added tests for all Phase 2 scenarios

---

### 2. Warehouse Entries (Type 21/22) Excluded from CAPE (effective July 7, 2026)

**What changed**: Effective July 7, 2026 (CSMS #69127837), CBP no longer accepts warehouse entries (Type 21 — Warehouse Entry, Type 22 — Re-warehouse) on CAPE declarations. Any such entry submitted on or after July 7, 2026 is rejected with "ENTRY TYPE NOT ALLOWED."

**Important nuance**: Warehouse **withdrawals** (different CBP type codes) remain eligible — IEEPA duty is paid at the time of withdrawal, not at warehouse entry. Only the warehouse *entry* itself is excluded.

**Retroactive impact**: Warehouse entries *accepted* on CAPE declarations between April 20, 2026 (Phase 1 launch) and July 6, 2026 without a corresponding warehouse withdrawal will NOT be reliquidated with an IEEPA duty refund.

**Source**: CSMS #69127837; Alba/WhatsUp Trade; Sobel Network Shipping.

**Code change**:
- Added `"21"` and `"22"` to `EXCLUDED_ENTRY_TYPES` in `src/lib/tariff-calculator.ts`
- Added `"21"` and `"22"` to `EXCLUDED_ENTRY_TYPES` in `src/lib/tariff-audit.ts`
- Exclusion reason message for Types 21/22 notes that warehouse withdrawals remain eligible
- Added tests for Type 21 and Type 22 exclusion

## 🔄 CAPE Phase 3 — NOT Yet Launched

**Status**: As of August 19, 2026, CBP informed the Court of International Trade that it **cannot launch Phase 3** and has offered **no opening date**.

**What Phase 3 will cover**: "Finally liquidated" entries (liquidated more than 80 days before the CAPE filing date). A July 15–17, 2026 CIT court order directed CBP to reliquidate certain finally liquidated entries across ~3,700 IEEPA cases — but CBP's technical systems are not ready to process these.

**Impact on calculator**: No code changes. The current "excluded_expired" / `filingMethod: "litigation"` path for entries beyond 180 days remains correct. The 80-day → protest window for 80–180 day liquidated entries also remains correct. When Phase 3 launches, the protest path for 80–180 day entries may shift to `cape_phase3`, and the `excluded_expired` status may partially unlock.

**Monitor note**: Re-check monthly or after any CBP CSMS alert referencing Phase 3.
