## 2. CAPE Phase 2 Status — LAUNCHED June 29, 2026

**This is the primary action item.** CBP deployed Phase 2 to the ACE portal on June 29, 2026.

### What Phase 2 covers

| Category | Phase 1 status | Phase 2 status |
|---|---|---|
| Unliquidated standard entries (type 01/02/06) | ✅ Eligible | ✅ Eligible |
| Liquidated within 80 days | ✅ Eligible | ✅ Eligible |
| Reconciliation-flagged entries (01/02/06, Type 09 not yet filed) | ❌ Excluded | ✅ **Now eligible** |
| Unliquidated AD/CVD entries | ❌ Excluded | ✅ **Now eligible** |
| Type 08 (Duty Deferral) | ❌ Excluded | ❌ Still excluded |
| Type 09 (Reconciliation entry itself) | ❌ Excluded | ❌ Still excluded |
| Type 23 (TIB) | ❌ Excluded | ❌ Still excluded |
| Type 47 (Drawback) | ❌ Excluded | ❌ Still excluded |

### Critical sequencing rule (reconciliation-flagged entries)

> **File the CAPE declaration BEFORE filing the Type 09 reconciliation entry.**  
> Once the Type 09 is filed, the underlying entries (01/02/06) become permanently ineligible for CAPE processing in all phases.

This is a hard failure point for brokers who do not know the rule. The `reviewNote` in `checkEligibility()` now surfaces this warning for all reconciliation-flagged entries.

### AD/CVD entries in Phase 2

Entries with AD/CVD overlays that are unliquidated are now eligible via CAPE Phase 2. These carry a `needsReview: true` flag because pending liquidation instructions may affect CAPE processing. The previous `excluded_adcvd` status is no longer returned for unliquidated entries; existing DB rows with that status route to `legal_required` in `getRoutingBucket()` (still appropriate for old data).

## 5. CAPE Rejection Trends

- **Last known rejection rate**: ~15% (CBS News, Phase 1) — no material update found for Phase 2 rejection rate
- **Top rejection causes** (updated analysis from Phase 1 data):
  1. HTS classification mismatch — declaration HTS doesn't match CBP entry record (~primary cause)
  2. Valuation inconsistency — declared value differs from CBP's record beyond tolerance
  3. Country-of-origin discrepancy
  4. Section 232/301 stacking errors — attempting to refund non-IEEPA duty layers
  - Together these account for ~79% of Phase 1 rejections
- **Key error codes still active**: `ENTRY ON DRAWBACK`, `PROTEST ON ENTRY`, `ENTRY SUMMARY UNDER REVIEW`, `NO IEEPA HTS ON ENTRY`, `STATEMENT PROCESSING NOT COMPLETE`

No evidence of CAPE system outages or elevated rejection rates specific to Phase 2 launch.

## 6. CAPE Phase 3

- **Coverage**: Finally liquidated entries (beyond the standard 80-day window)
- **Eligibility gate**: CIT litigants only — importers who have filed suit at the Court of International Trade
- **Timeline**: On track for late July 2026 per Green Worldwide Shipping (published ~July 2026)
- **Court mechanism**: CIT will direct CBP to reliquidate certain finally-liquidated entries via orders entered in ~3,700 IEEPA cases assigned to the court
- **Impact on calculator**: None needed. The `litigation` filing method already correctly routes entries past the protest window. Phase 3 is not available to general filers — only plaintiffs in active CIT cases.
